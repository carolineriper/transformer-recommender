# MovieLens data

This project uses the MovieLens 1M dataset. Download it from the
[official GroupLens page](https://grouplens.org/datasets/movielens/1m/) and
extract the archive into this layout:

```text
data/
└── raw/
    └── ml-1m/
        ├── movies.dat
        ├── ratings.dat
        ├── users.dat
        └── README
```

`data/raw/` is excluded from Git. The dataset is not redistributed by this
repository; its bundled README contains the applicable usage terms.
